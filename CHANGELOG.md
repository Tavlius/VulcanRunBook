# Changelog

## v1.1.0 - first public release

- Now **Vulcan RunBook** (formerly Run Log), part of the Vulcan Suite. `/runbook` opens it;
  `/runlog` and `/rlog` still work.
- New: `/runbook backup` and `/runbook restore` (also buttons in the history window). Copy all
  your runs and settings as compressed text to keep outside the game, and paste it back later.
  Restoring keeps runs you made after the backup.
- New: a clear warning when the Forever client fails to load your saved data, saying what may
  be missing and which file to keep. A character file that didn't load is spotted too.
- Sync uses a new message name, so both of you need this version to see each other.
- `/runbook check` shows the add-on version (`dev` when run from source).
- Frame accent in the Vulcan Suite's ember orange.

## 1.0.0 (as Run Log)

- First version: run log with clear times, boss splits, deaths, wipes, drops, gold and XP,
  notes, per-dungeon stats, the instance cap, duo sync and the group view.
